# Project conventions

- Write all project documents (concept board, PRD, process maps, plans, reviews, reports) as self-contained HTML files under `docs/`, not Markdown. Use the Almiras look of `docs/concept.html` (fonts from `prototype/pdf/brand/fonts/`, navy/sand/orange tokens).
- The only Markdown files allowed are this `CLAUDE.md` and installed skills under `.claude/skills/`, because the tooling requires them.
- Process maps are BPMN 2.0 and are viewed in HTML.
- Start every session by reading `docs/concept.html` (and `docs/prd.html` once it exists).
